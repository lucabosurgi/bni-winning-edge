Member Badge Kit

Everything you need to link your website to the network. Copy, paste, done — under five minutes on WordPress, Wix, Squarespace, GoDaddy and every common builder.

Before you start

In the snippets below, replace YOUR-BUSINESS-NAME — in both places it appears — with the last part of your own profile page's address. Find your page in the member directory — the address looks like winningedgepartners.com/members/your-business-name.

Option A — the badge (image + link)

Best for footers and sidebars. Paste this into an HTML / Embed block:

<a href="https://winningedgepartners.com/members/YOUR-BUSINESS-NAME?via=YOUR-BUSINESS-NAME"
   title="Winning Edge Partner — Spring Hill, Florida">
  <img src="https://winningedgepartners.com/badge/badge.svg"
       alt="Winning Edge Partner — Spring Hill, Florida"
       width="220" height="64" style="border:0;" loading="lazy">
</a>

Option B — the one-line text link

Invisible-weight, strongest for search engines, fits any footer:

<p>Proud partner of
  <a href="https://winningedgepartners.com/members/YOUR-BUSINESS-NAME?via=YOUR-BUSINESS-NAME">Winning Edge Partners — Spring Hill's trusted business network</a>.
</p>

Option C — the live spotlight widget (optional upgrade)

A small card that rotates through fellow members automatically — live demo:

Add it with two lines:

<div id="winning-edge-widget"></div>
<script src="https://winningedgepartners.com/widget/widget.js" async></script>

Where to paste it — step by step

WordPress: log in to your dashboard, go to Appearance → Widgets (or edit the page with your page builder), add a Custom HTML block where you want it, paste the snippet, and click Update.

Wix: in the editor click Add Elements → Embed Code → Embed HTML, paste the snippet into the box, drag it into position, and click Publish.

Squarespace: edit the page or footer, click an insert point and choose the Code block, paste the snippet, and save.

GoDaddy Website Builder: edit your site, add a section, search for HTML — Embed Custom Code, paste the snippet, and publish.

Any other builder: look for a block called HTML, Embed or Custom Code — they all work the same way. Tip: the badge or text link belongs in your footer so it appears on every page; the spotlight widget looks best in a sidebar or near the bottom of your home page. Stuck?
